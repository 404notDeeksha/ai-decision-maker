# 04 — Success Metrics & Definition of Done

## North-star metric
% of sessions that reach the **Results** screen (i.e. actually finish).

## Secondary metrics
- Follow-up completion rate
- Share clicks (and posts to X)
- Time from landing to results (target < 60s)
- Return visits / repeat use

## Definition of Done for the MVP
- [ ] End-to-end flow works for 20 varied test dilemmas.
- [ ] LLM output matches the JSON schema on ≥ 95% of runs.
- [ ] No login required; works on mobile viewport.
- [ ] Reset clears all state cleanly.
- [ ] Share produces valid text + a working link.
- [ ] App is publicly deployed and ready to post on X.

## Validation plan (Phase 5 preview)
Post to X, watch completion rate, collect a handful of user reactions, then decide what L2 needs.
