# 01 — Product Definition

## Problem
People face everyday dilemmas (job A vs job B, buy vs rent, move vs stay) and get stuck.
Existing advice is slow, unstructured, or biased toward whoever you ask.

## Solution
A public web app that asks a few targeted questions, then returns a structured analysis:
1. Restated dilemma
2. Key priorities & constraints
3. Pros / cons / trade-offs per option
4. One likely blind spot
5. A recommendation + reasoning + what would change it

## Target user
- 18–35, active on X (Twitter), deciding alone.
- Wants a fast second opinion without signing up.

## Value proposition
> Structured clarity in under a minute — no account, no fluff.

## Non-goals for MVP
No accounts, no saved history, no dashboards, no payments, no team features.
